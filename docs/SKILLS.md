# Elyra Skill 广场

首页保留中间创作输入框，将原项目展示区改为 Skill 卡片。项目管理仍在「我的项目」，原画布、素材与可替换 API 保留。

## 客户怎么用

1. 在首页选择 Skill，可按类别、关键词或收藏查找。
2. 填写需求，需要时上传参考图，选择执行方式。
3. 点击「使用 Skill」：把要求和参考图原子添加到当前画布，随后通过现有 Agent 与模型适配器执行。输出连接到任务节点。
4. 需求保存在可编辑节点中，可调整后手动重跑。刷新只恢复已有节点与结果，不重新生成。

内置四个 Skill：商品摄影师、品牌海报设计、小红书封面、电影感分镜。分镜交付是一张四格图，不是视频。封面由内置 Image Gen 制作，是示意作品，不是本轮 Skill 运行的真实模型产物。

## 添加给所有客户

编辑 `src/skills/catalog.json`，追加一个配置对象，将封面放进 `public/assets/skills/`，重新构建发布。完整示例在 `public/skill-example.json`。内置目录随项目交付，不依赖开发者的浏览器数据。

| 字段 | 含义 |
| --- | --- |
| schemaVersion | 固定 1 |
| id / version | 唯一英文小写 ID / 三段版本号，如 `my-poster` / `1.0.0` |
| name / description / category | 卡片名称、说明、分类 |
| cover | 本站 `/assets/` 下 PNG、JPG、JPEG、WebP 路径 |
| output | `image` 或 `video` |
| reference | `none`、`optional`、`required`；视频必须 required |
| deliverable | 明确交付物及必要限制 |
| fields | 1–6 个字段，key、label、required，选填 placeholder、defaultValue |
| instructions | 创作要求，通过 `{{字段key}}` 插入客户填写的内容 |

所有字段必须在 instructions 中使用；不能引用未声明字段。每个输入最多 800 字，模板定义最多 6000 字；实际编译后的需求（含 Skill 名称和版本）必须不超过现有 Planner 的 4000 字上限，超限在创建节点前拒绝。新 Skill 不能自行加入脚本、网络工具、API 密钥或绕过既有服务端授权。视频仍受当前适配器的单图、4 秒能力限制。

## 不改代码的本机试用

首页「添加 Skill」→「下载示例」→修改 JSON→「导入 Skill 文件」。支持一次 1–20 个、累计最多 50 个自定义 Skill。校验通过后原子写入；重复 ID、未知字段、错误模板或超限文件会拒绝，已有 Skill 不受影响。

本机导入和收藏保存在当前浏览器。它们不是共享市场，也不会自动同步到客户。要让所有客户可用，请按上一节放入内置目录。移除本机 Skill 不删除它已创建的画布节点或作品。损坏目录读取时保留原始数据，不静默覆盖。

## 执行与验证边界

- Skill 显式点击产生仅存在于当前页面内存的一次性执行许可，绑定项目、节点、冻结输入、模型和有效期。刷新、重复消费或切换离开画布都不能重新触发自动执行。
- 图像字节先经现有上传清理流程存入 IndexedDB，读取校验后才发布引用与节点；跨项目参考图拒绝。
- 真实模型沿用原规划、预算、请求凭证、产物归档和失败恢复链。参考图的传输同意在 Skill 表单采集；之后手动重跑仍沿用节点确认规则。API 更换入口位于画布的「API 设置」。
- 预览服务（4318）关闭真实模型，图片 Skill 默认「本地流程演练」，返回固定音箱示例图。真实供应商的生成质量、费用和视频输出未在本轮验收。
- 模板是声明式创作流程，当前每次执行一个图片或视频任务；不支持任意代码 Skill、批量调度或自动多步素材编排。

## 维护和测试

`src/skills.ts` 负责格式与参数校验、导入和收藏；`src/skill-launch.ts` 负责原子图变更及一次性许可；`src/SkillGallery.tsx` 负责卡片和表单。新节点复用 `workflow-graph` 和现有 App 执行链，没有第二套任务系统。

`src/skills.test.ts` 覆盖内置模板、导入拒绝、50 项恢复、损坏数据保留、项目持久化、原子引用、跨项目与授权拒绝、刷新和重复消费。

封面最终文件在 `public/assets/skills/`。内置 Image Gen 提示方向分别为：奶油色日光香水商业摄影、嫩绿植物与 Good Things Grow 编辑海报、暖橙色生活笔记封面拼贴、同一旅行者的海岸四格电影分镜。全部为独立生成资产，使用现有 Elyra SVG 品牌标记。
