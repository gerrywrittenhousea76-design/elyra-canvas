# ELYRA Canvas

一个由 Agent 控制的节点式 AI 创作画布，包含图片与视频任务、参考连线、版本管理、Skill 一键调用，以及可替换的模型 API。

## 功能

- 文本、图片任务、视频任务节点与引用连线；添加、拖动、缩放、排列、撤销与重做。
- 统一 Agent 面板，可通过明确指令控制节点和选区。
- 商品摄影、品牌海报、小红书封面、电影分镜四个内置 Skill，支持 JSON 导入。
- Agent 规划、图片与视频分别配置协议、地址、模型和密钥；新协议可通过服务端适配器扩展。
- 浏览器本地多项目、素材、输出版本与回收站；当前没有账号系统和云同步。

## 本机演示

需要 Node.js 22+。以下步骤说明维护者已验证的启动方法，技术可运行不构成额外使用授权。

```sh
npm ci
npm run preview
```

打开 http://127.0.0.1:4318/ 。演示模式使用固定音箱样例，禁止真实模型请求，不需要 API Key。它用于查看画布、节点与 Skill 调用流程，不代表真实生成质量。

## 配置真实模型

取得所需授权后，使用自己的供应商账号和密钥：

```sh
npm run dev
```

默认地址 http://127.0.0.1:4175/ 。在画布工具栏的「API 设置」中分别设置规划、图片、视频供应商，保存后重启服务。协议兼容性取决于供应商实际能力，新增协议需要适配器。详细步骤见 [API 接入指南](docs/API-PROVIDERS.md)。

API Key 仅保存在本机服务端私有目录，不随仓库交付。不要公开提交 `.env` 或 `.elyra-runtime`。

## Skill 与画布指令

首页选择 Skill → 填写需求和参考图 → 使用 Skill → 任务及结果进入画布。分镜 Skill 生成四格图片。Skill 定义与扩展见 [指南](docs/SKILLS.md)。

可在 Agent 面板尝试：

- 添加文本节点：一只蓝色音箱，柔和晨光
- 添加图片节点
- 选中对象向右移动100像素
- 选中对象横向排列
- 全部对象网格排列
